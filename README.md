# Elite Boxing Gym

A responsive boxing gym website designed to present classes, memberships, training information, and business details through a modern front-end experience.

## Overview

Elite Boxing Gym is a front-end web development project focused on building a professional digital presence for a fitness and boxing business.

The goal was to combine strong visual design with clear information architecture and responsive behavior.

## Features

- Responsive website design
- Class information
- Membership details
- Gym information
- Interactive front-end behavior
- Mobile-friendly navigation
- Modern fitness-focused design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

- Visual hierarchy
